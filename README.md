# inside-terminal-images

Repo público, solo de imágenes. No hay código de trading ni de análisis aquí
-- ese vive en repos privados aparte. Esto solo guarda las tarjetas ya
renderizadas (ES, NQ, GEX, etc.) para que un dashboard web pueda mostrarlas
sin depender de que una Mac esté encendida.

Las imágenes se borran automáticamente al final de cada día de mercado
(ver `.github/workflows/wipe-daily.yml`), así que este repo nunca acumula
historial -- en cualquier momento solo tiene lo del día en curso.
